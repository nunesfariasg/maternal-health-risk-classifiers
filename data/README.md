# Origem dos dados

CSV original de Maternal Health Risk, UCI id 863, obtido em 26/11/2026 de:
https://archive.ics.uci.edu/static/public/863/maternal+health+risk.zip

Ahmed, M. (2020). Maternal Health Risk [Dataset]. UCI Machine Learning Repository.
DOI: https://doi.org/10.24432/C5DP5D. Licença: CC BY 4.0.

SHA-256 do CSV sem alterações:
`a1f7025719f84715096e0d1f95ae2e56b57809b9b15449e1836c96a7d976ae9b`.

O carregador verifica o hash. O portal informa 1.013 instâncias, mas o arquivo
baixado contém 1.014 linhas de dados. O experimento utiliza a contagem do arquivo.
O CSV permanece original: remoção das 562 repetições exatas ocorre em memória.
Não há nomes ou identificadores pessoais no arquivo. Os dados são públicos e reais,
não são mocks. Consulte `results/data_audit.json` para a auditoria completa.
